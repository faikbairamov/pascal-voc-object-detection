# Commit messages

Use scoped Conventional Commits for every commit: `type(scope): short description`.
A scope is required. Use an appropriate type such as `feat`, `fix`, `docs`,
`refactor`, `test`, or `chore`, and a scope naming the affected area.
For example: `docs(report): update report` or `feat(inference): add image upload`.

Write every commit subject and body entirely in lowercase, including acronyms.
